# Code of Conduct

## Our standard

Contributors are expected to be respectful, constructive and technically honest. Disagreement about implementation is welcome; harassment, discrimination, personal attacks and deliberate misinformation are not.

## Educational integrity

When contributing technical material:

- Distinguish tested behavior from assumptions.
- Identify version-sensitive behavior.
- Do not present insecure shortcuts as production best practice.
- Never publish credentials or private information.

Maintainers may remove content that is unsafe, abusive, plagiarized or technically misleading.
