# Kubernetes Certification Preparation

This section maps practical skills to common Kubernetes certifications. Always verify the current exam objectives and allowed resources with the certification provider before scheduling an exam.

## KCNA

Focus on Kubernetes fundamentals, cloud-native concepts, orchestration basics, architecture, workloads, networking, storage and observability.

## CKA

Prioritize hands-on cluster administration: workloads, scheduling, networking, storage, security, troubleshooting, cluster maintenance and operational diagnosis.

## CKAD

Prioritize application design and deployment: manifests, configuration, services, probes, resources, networking, jobs and application troubleshooting.

## CKS

Prioritize security: RBAC, Pod Security, runtime/image security, network policies, secrets, supply-chain controls, audit and cluster hardening.

## Study method

1. Learn the concept.
2. Perform the task without notes.
3. Break it intentionally.
4. Diagnose from evidence.
5. Repeat under time pressure.
6. Explain the decision aloud.

Avoid treating leaked exam content as study material. Build genuine operational skill instead.
