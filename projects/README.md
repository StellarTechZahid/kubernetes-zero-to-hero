# Progressive Kubernetes Projects

## Project 1 — Static Web Service

Deploy a stateless web app with Deployment, Service, probes and resource requests.

## Project 2 — Two-Tier Application

Build frontend + API. Add ConfigMap, Secret, Service discovery and NetworkPolicy.

## Project 3 — Persistent Application

Add a stateful component with PVCs, backup documentation and restore testing.

## Project 4 — Production Web Platform

Add ingress/Gateway routing, TLS, autoscaling, PodDisruptionBudget, topology-aware placement and observability.

## Project 5 — Helm Platform Package

Package the application as a chart with documented values, environment overlays and safe defaults.

## Project 6 — CI/CD Pipeline

Implement tests, container build, vulnerability checks, registry publication and rollout verification.

## Project 7 — GitOps Platform

Move environment delivery to GitOps. Demonstrate pull-request review, reconciliation, drift detection and rollback.

## Project 8 — Cloud Kubernetes

Deploy the same workload to EKS, AKS or GKE. Document provider-specific identity, networking, storage and load-balancing decisions.

## Final capstone — Production-grade Kubernetes platform

Design and implement a multi-service platform with:

- Secure workload identity
- Least-privilege RBAC
- Network isolation
- Persistent storage where required
- Health probes and resource policies
- Autoscaling
- Metrics, logs and traces
- CI/CD and GitOps
- Backup/recovery plan
- Disaster scenarios
- Cost model
- Architecture diagram
- Operations runbook
- Incident response playbook

A project is complete only when another engineer can deploy it, understand it, observe it, troubleshoot it and recover it from documented failures.
